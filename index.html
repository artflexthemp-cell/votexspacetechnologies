Meet Votex-Sat1

Votex-Sat1 is an Earth-based, satellite-inspired weather monitoring project. It is designed to work here on Earth, not to travel into space.

What is it designed to do?

  • Use an ESP32 microcontroller to process sensor readings.
  • Measure local temperature.
  • Measure humidity, the amount of water vapour in the air.
  • Send readings over Wi-Fi to a dashboard that can be viewed in a browser.

Current goal: build and test the weather monitoring system.
