Our Main Project

Meet Compassion.Sat 1

Compassion.Sat 1 is an Earth-based, satellite-inspired technology project. It is designed to explore how electronic sensors and microcontrollers can help us understand our surrounding environment.

Compassion.Sat 1 — Environmental Monitoring

The project aims to use an ESP32 microcontroller and suitable sensors to collect local environmental measurements.

Planned features include temperature measurement, humidity measurement, and a simple dashboard for viewing readings through a web browser.

This is an Earth-based project. It is not an orbital satellite and is not designed to launch into space.
