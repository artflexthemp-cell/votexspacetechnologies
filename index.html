Featured Project

Votex-Sat1

Votex-Sat1 is our Earth-based, satellite-inspired environmental monitoring project. It is designed to explore how a small electronic device can measure local environmental conditions.

Our planned capabilities

  • Measure temperature using a suitable sensor.
  • Measure humidity using a suitable sensor.
  • Collect readings using an ESP32 development board.
  • Display readings on a local web dashboard.
  • Learn how environmental data can be recorded and understood.

Votex-Sat1 is an Earth-based prototype, not an orbital satellite. Its capabilities will depend on the sensors and software we successfully build and test.
