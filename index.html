Our Main Project

Compassion.Sat 1

Earth-Based Project Environmental Monitoring

Compassion.Sat 1 is our Earth-based, satellite-inspired environmental monitoring project. It is designed as a practical way to learn about sensors, electronics, microcontrollers, and environmental measurements.

The project aims to use an ESP32 development board and compatible sensors to gather local environmental readings. These readings can then be presented through a simple dashboard viewed in a web browser.

What We Aim to Measure

  • Temperature around the device.
  • Humidity in the surrounding air.
  • Additional environmental measurements as suitable sensors are added.
  • Readings collected and processed by the ESP32.
  • Measurements displayed through a local web dashboard.

Compassion.Sat 1 operates on Earth. It is not designed to orbit Earth or launch into space. Its capabilities will depend on the sensors and hardware installed.

Project Details
How It Works

Inside Compassion.Sat 1

The project brings together hardware, programming, environmental sensors, and a dashboard.

01

Environmental Sensors

Compatible sensors detect environmental conditions such as temperature and humidity and provide readings that the controller can process.

02

ESP32 Controller

The ESP32 runs the program, reads supported sensors, and can communicate with a device over a Wi-Fi network.

03

Web Dashboard

A simple web page can display the readings so that a user can view the available information in a browser.

Our Development Process

We plan to build the project in stages: prepare the components, connect the sensors safely, write and test the code, verify the readings, and then develop the dashboard. Each feature will be tested before additional features are introduced.
